# atol-genomeassembly-inputs

Prepares QC'd files for input into sanger-tol/genomeassembly pipeline; creates config file

1. Merge and reformat (.fq.gz -> .fa.gz) long-read files (`seqkit`)
2. Merge and reformat (R1.fq.gz, R2.fq.gz -> .cram) hi-c files (`samtools`)
3. Generate .cram.crai and .cram.flagstat files for hi-c files (`samtools`)
4. Create config.yaml for input into sanger-tol/genomeassembly pipeline

## Installation

To install the latest version on Pawsey:

```
module load nextflow/25.04.6
nextflow pull amytims/atol-genomeassembly-inputs -r dev
```

## Usage

### Merge and reformat hifi + hic files; create config.yaml file

```
nextflow run amytims/atol-genomeassembly-inputs \
    -r dev \
    -profile pawsey \
    --yaml <PATH/TO/DATAMAPPER/OUTPUT/YAML> \
    --longread_indir ./results/processed_reads/hifi \
    --hic_indir ./results/processed_reads/hic \
    --outdir ./results/genomeassembly_inputs 
```

### Full usage

```
options:
    --help
            Show this help message and exit

input:
    --yaml <PATH/TO/YAML/FILE>
            Path to the .yaml file generated by the data mapper query
        
    --longread_indir
            Path to directory containing PacBio read files for DToL's genomeassembly
            pipeline.
            Default is './results/processed_reads/hifi'

    --hic_indir
            Path to directory containing Hi-C read files for DToL's genomeassembly
            pipeline.
            Default is './results/processed_reads/hic'

output:
    --outdir <PATH/TO/OUTPUT/DIRECTORY>
            File path to where read files and config.yaml should be stored
            Default is './results/genomeassembly_inputs'
```
